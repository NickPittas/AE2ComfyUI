# AE ↔ ComfyUI Bridge Protocol

HTTP, localhost or trusted LAN only. AE is the client; ComfyUI hosts all
routes under `/ae_bridge/`. No server runs inside AE.

All endpoints are registered by `comfyui/ae_bridge` on ComfyUI's PromptServer
(`{host}:{port}`, default `127.0.0.1:8188`).

## `GET /ae_bridge/health`

```json
{"ok": true, "app": "ae2comfyui"}
```

## `POST /ae_bridge/assets`

Multipart form upload. AE sends this once per exported file (main image/video
and mask) before queueing a workflow.

Fields:

| field | content |
|---|---|
| `file` | binary payload (PNG, JPG, MOV, MP4) |
| `job_id` | UUID generated by AE per run |
| `asset_id` | `main` or `mask` |
| `metadata` | full `job_manifest.json` serialized as a JSON string |

Response:

```json
{"ok": true, "path": "/tmp/.../ae_bridge/<job_id>/main.png"}
```

Errors: 400 (missing fields, path escape), 404 (unknown job after TTL).

Server stores assets under
`folder_paths.get_temp_directory()/ae_bridge/<job_id>/` and registers them in
the in-memory job store (`JOB_TTL_SECONDS = 3600`).

## `GET /ae_bridge/jobs/{job_id}`

```json
{
  "ok": true,
  "metadata": { "...": "job_manifest fields" },
  "assets": {"main": "main.png", "mask": "mask.mp4"},
  "result": null
}
```

## `GET /ae_bridge/jobs/{job_id}/result`

Streams result bytes after `ToAE` / `ToAEVideo` has run.

Headers:

```text
Content-Type: image/png | image/jpeg | video/quicktime | video/mp4
X-AEBridge-Format: png | jpg | mov | mp4
X-AEBridge-Width: <px>
X-AEBridge-Height: <px>
X-AEBridge-Frame-Count: <n>        (video only)
X-AEBridge-FPS: <fps>              (video only)
X-AEBridge-Duration: <seconds>     (video only)
```

404 when the result is not ready. The panel also polls ComfyUI `/history` to
know when to call this.

## `GET /ae_bridge/workflows`

```json
{
  "ok": true,
  "workflows": [
    {
      "id": "wf-ab12cd34 | saved:inpaint.json",
      "name": "My Workflow",
      "source": "open | saved",
      "has_from_ae": true,
      "has_to_ae": true,
      "media": "image | video | both"
    }
  ]
}
```

`open` entries are published by the ComfyUI frontend extension
(`web/ae_bridge.js`) and expire 60 s after the tab stops publishing.
`saved` entries come from scanning `AE_BRIDGE_WORKFLOW_DIRS` (default
`~/.ae2comfyui/workflows/` and the repo `workflows/` directory) for
API-format workflow JSON.

## `POST /ae_bridge/workflows`

Frontend publisher (ComfyUI browser tab) pushes the open workflow:

```json
{"workflows": [{"id": "...", "name": "...", "has_from_ae": true,
                "has_to_ae": true, "media": "image", "prompt": {}}]}
```

`prompt` is the API-format prompt produced by `app.graphToPrompt()`.

## `POST /ae_bridge/run_workflow`

```json
{"workflow_id": "...", "client_id": "optional"}
```

Response:

```json
{"ok": true, "submitted": false, "client_id": "...", "prompt": {}}
```

The server returns the stored prompt; **AE patches it and POSTs `/prompt`
itself** (same proven pattern as the Nuke bridge — no version-dependent
server internals).

## Workflow patching (AE side)

Before POST `/prompt`, AE deep-copies the prompt and injects:

| node class_type | inputs patched |
|---|---|
| `FromAE`, `FromAEVideo` | `job_id`, `asset_id` |
| `ToAE` | `job_id`, `filename_prefix` |
| `ToAEVideo` | `job_id`, `filename_prefix`, `video_meta_json` (serialized manifest) |

Prompt text: the `FromAE` `prompt` STRING output is the canonical prompt
source inside the workflow. Additionally, when a workflow carries a
`prompt_node_id` marker, AE patches that node's text input directly.

## job_manifest.json (exact fields)

Written by AE into the staging folder and uploaded with every asset.

```json
{
  "job_id": "uuid",
  "media_type": "image | video",
  "width": 0, "height": 0, "pixel_aspect": 1.0,
  "fps": 0.0, "frame_count": 1, "duration_seconds": 0.0,
  "timeline_start_seconds": 0.0,
  "timeline_end_seconds_exclusive": 0.0,
  "range_source": "work_area | layer_range | comp | current_frame",
  "comp_id": 0, "selected_layer_index": 0,
  "placement": "above_selected_layer | top_of_comp",
  "mask_mode": "none | use | invert",
  "prompt": "",
  "color_engine": "adobe_icc | ocio",
  "project_working_space": "",
  "project_bits_per_channel": 16,
  "linearize_working_space": false,
  "linear_blending": false,
  "bridge_color_mode": "preserve_working_space | srgb | rec709 | preserve_rgb",
  "output_color_space": "",
  "preserve_rgb": true
}
```

## Mask convention

ComfyUI MASK: `0 = keep/opaque, 1 = masked/transparent`.
AE alpha: `1 = opaque, 0 = transparent`. `FromAE` converts `mask = 1 - alpha`.
`invert` mode is applied AE-side before export.

## Result import (AE side)

- Validate result width/height, frame count, fps against the manifest.
  Frame-count mismatch → hard error, no import.
- Still: place at manifest `timeline_start_seconds`.
- Video: anchor at manifest `timeline_start_seconds` (work-area start when
  active), set in/out from returned frame count / fps.
- Placement: above `selected_layer_index`, or index 1 for `top_of_comp`.
